# 物品栏与装备

物品栏包含主物品栏、背包、装备栏和饰品栏。

| 区域 | 用法与规则 |
| --- | --- |
| 主物品栏 | 默认 45 格，可配置为 30 格或原版 15 格。原版快捷栏保留 15 格。 |
| 背包栏 | 默认独立装备背包；MC 风格还允许把装着物品的背包收进玩家物品栏。 |
| 衣服栏 | 启用额外装备栏时，指定原版衣物改用独立栏位，可与身体护甲搭配。不是所有身体装备都算衣服。 |
| 启迪之冠栏 | 启用额外装备栏时，启迪之冠使用独立栏位；原有装备效果保留。 |
| 饰品栏 | 包含术石、两个戒指位、护符和遗物栏。不同物品要放入适配栏位。 |
| 护符栏 | 原版六种宝石护符可装备在此栏。 |
| 遗物栏 | 不死图腾在这里装备并生效。 |
| 扩展栏 | 可显示受支持的第三方装备；能力勋章是否同时显示在原版栏位由配置决定。 |

## 打开与关闭

使用游戏的“检查自己”入口打开界面；关闭可用取消键或物品栏键。键位以你在游戏中设置的控制绑定为准。

> 启用七咒玩法后，第一个戒指位会被绑定的七咒之戒占用。
