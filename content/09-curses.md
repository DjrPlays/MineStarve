# 七咒之戒与神秘遗物

神秘遗物默认关闭。启用后会自动给予、装备并绑定七咒之戒，是持续性的挑战规则。

## 七项诅咒

| 诅咒 | 具体影响 |
| --- | --- |
| 受难 | 最终承受的战斗伤害 ×1.35。 |
| 众生敌意 | 中立生物敌视，招募与驯服受限；角色固有伙伴等部分生物不受影响。 |
| 甲胄失效 | 护甲效果只发挥 75%。例如原本 80% 吸收按此折算为 60%，再参与后续结算。 |
| 猎物反噬 | 对普通目标伤害 ×0.8；对首领 ×0.7。 |
| 永燃 | 默认燃烧持续时间为 5,000 秒，并限制普通熄灭；火焰保护可缩短时间。 |
| 灵魂破裂 | 每次死亡增加一层 20% 生命上限惩罚，最多三层，共 60%。 |
| 失眠 | 不能正常睡眠；夜晚和洞穴黑暗时理智下降加倍。 |

## 祝福与收益

| 祝福 | 实际用途 |
| --- | --- |
| 福祸相依 | 幸运＋1。 |
| 强取豪夺 | 自带抢夺Ⅰ；与武器抢夺合计最高按Ⅳ计算，额外普通掉落概率最高 40%。 |
| 以战养战 | 符合条件的敌对击杀治疗：普通 1 点，大型 5 点，首领 15 点。 |
| 禁术灌注 | 有效附魔等级＋10；不提供可直接支付的实际等级。 |
| 七咒馈赠 | 获得七咒专属掉落资格。 |
| 暗影随行 | 物品栏内可随身访问与麦斯威尔魔术箱共享的储物。 |
| 我命由我 | 获得制作、装备、触发七咒遗物的权限。 |

## 处理永燃与灵魂破裂

永燃默认持续 5,000 秒，潮湿度达到 35 或处于冻结状态时可以熄灭；部分喷水效果也可灭火。死亡层数需在符合远古二级科技条件的远古站旁制作“灵魂缝合”，每次消耗 1 个生命护符与 4 个噩梦燃料，修复一层。

## 隐藏诅咒与绑定

隐藏诅咒生效时：受到击退距离 ×1.5，相关敌对生物追击时可无视墙体寻路。七咒之戒不能靠普通摘除、砂轮或喝奶解除。
