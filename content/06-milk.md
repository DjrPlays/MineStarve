# 铁桶与奶桶

成年皮弗娄牛可定期产奶。饮用奶桶可恢复生命和理智，并清除限时效果。

## 挤奶步骤

1. 使用 2 燧石和 2 硝石制作铁桶。
2. 把铁桶装备到手上，靠近可产奶的成年皮弗娄牛。
3. 右键选择“挤奶”。一次消耗一个空桶，得到一个奶桶。
4. 同一头牛需要等待 3 个游戏日恢复产奶；幼年牛不能挤奶。

| 项目 | 数值或结果 |
| --- | --- |
| 饮用收益 | 生命＋2，理智＋5，饥饿＋0 |
| 效果清理 | 清除适用的限时效果，包括有益效果 |
| 喝完以后 | 返还铁桶 |
| 常温保质期 | 3 个游戏日 |
| 变质产物 | 20% 概率黄油，否则腐烂食物；同时返还铁桶 |

> 喝奶会清除图腾提供的恢复、抗火与吸收等限时效果。牛奶不是七咒之戒的解绑道具，也不能代替灵魂缝合修复死亡层数。部分其他模组的限时效果可能无法清除。
