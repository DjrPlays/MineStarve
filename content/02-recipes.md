# 配方速查

主要制作配方的材料数量、科技要求和额外条件。基础建筑的制作仍遵循游戏本身的科技与角色条件。

| 物品或制作项 | 材料 | 科技与额外条件 |
| --- | --- | --- |
| 铁桶 | 燧石 ×2＋硝石 ×2 | 无需科技；工具分类 |
| 书 猪皮装订 | 莎草纸 ×3＋猪皮 ×1 | 一本科技；精炼分类 |
| 书 触手皮装订 | 莎草纸 ×3＋触手皮 ×1 | 一本科技；两种配方产物相同 |
| 橡木船 | 木板 ×3＋触手皮 ×1 | 航海一级科技；航海分类 |
| 橡木箱船 | 木板 ×6＋触手皮 ×1 | 航海一级科技；航海分类 |
| 麦斯威尔的魔术箱 | 蜘蛛丝 ×1＋木板 ×4＋噩梦燃料 ×9 | 七咒状态；无需普通科技 |
| 灵魂缝合 | 生命护符 ×1＋噩梦燃料 ×4 | 七咒状态且有灵魂破裂；远古二级科技站附近 |

## 这些物品通过其他方式获得

| 物品 | 获取方式 |
| --- | --- |
| 奶桶 | 手持铁桶，对可产奶的成年皮弗娄牛右键挤奶。 |
| 附魔书 | 给普通书随机附魔，或向普通书转移适用附魔。 |
| 不死图腾 | 每个克雷账号在世界中首次出生赠送 1 个；向猪王给予兔王武器可换取 2 个。 |
| 七咒之戒 | 启用神秘遗物后自动给予并绑定。 |

> 灵魂缝合是一项立即执行的修复制作：完成后修复一层灵魂破裂，不会留下可储存的药品。两种普通书配方做出的书是同一种，不能据此凑齐书架的三种书。
